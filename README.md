# Organograma Studio

Vitrine pública do **Organograma Studio**, projeto criado por Marcos Davi para visualização de estruturas organizacionais, comparação de cenários e apoio a decisões de equipe.

[Acessar a apresentação](https://xmarcosdavi.github.io/organograma-studio/)

Este repositório contém somente material de apresentação: página institucional, descrição do produto e imagem com dados fictícios. O código-fonte, as regras de negócio e os componentes internos da aplicação não são distribuídos publicamente.
